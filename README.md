## Overview

Studio Immens Quick Order supercharge the online ordering process for restaurants: a frontend menu experience for customers and a dedicated admin dashboard to manage categories, tables, orders and QR codes — all integrated with WooCommerce.

---

## Features

### 🍽️ Menu di ordinazione online
- Menu di ordinazione rapida per ristoranti, integrato con WooCommerce
- Frontend di ordinazione con gestione tavoli e categorie

### 🪑 Gestione tavoli e zone
- Tavoli e zone gestibili dall'admin
- Codice QR per tavolo (libreria QR integrata) per aprire il menu direttamente dal tavolo

### 📦 Ordini
- Gestione ordini con stati dedicati (es. consegna)
- Statistiche ordini

### 🎨 Personalizzazione
- Pagina **Settings**: configurazione generale del plugin
- Pagina **Style**: personalizzazione dell'aspetto del frontend

### ⚡ PRO (Studio Immens Quick Order Pro)
- **Warehouse**: movimenti di magazzino, soglie minime di scorta, alert e export CSV
- **Print Rules**: regole di stampa automatica per zona tavoli / categoria prodotto (integra le stampanti WooPrint)
- **Aggiornamenti automatici** via licenza

## Installation

1. **Da WordPress**: Carica il file ZIP su **Plugin > Aggiungi nuovo > Carica plugin**
2. Attiva il plugin
3. Vai su **Quick Order** nel menu admin per configurare menu, tavoli e ordini

### Requisiti

| Requisito | Minimo |
|-----------|--------|
| WordPress | 6.5+ |
| PHP | 7.4+ |
| WooCommerce | attivo |

---

## Usage

1. **Quick Order** — dashboard principale: gestione menu, categorie e ordini
2. **Settings** — configurazione generale (orari, modalità ordinazione, QR)
3. **Style** — personalizzazione grafica del frontend
4. Stampa il QR di un tavolo e apri il menu da mobile per un ordine di prova
